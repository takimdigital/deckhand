# v2.1.0 — research you can check, not trust

**Every fact your plan is built on now carries the exact sentence it came from, and Deckhand re-opens the page to
check that sentence is really there.**

- **Facts with proof.** Each research fact (a competitor's price, a customer complaint, a local rule) is stored with
  its page and a word-for-word quote, labelled VERIFIED, SECONDARY, INFERRED or NOT FOUND.
- **Checked, not trusted.** `dh research verify` fetches every page and fails any quote that isn't on it. Pages that
  block robots or need a browser are marked "unchecked", never silently passed.
- **Your customers' words, not the AI's.** The vocabulary used for the plan, the copy and SEO is copied from real
  pages, because AI-guessed terms make search worse on unfamiliar trades.
- **One short research card** tells every agent how to search: read results before rewording, change one thing at a
  time, never repeat a failed query, stop when the answer is proven.
- **Team research without waste.** Agents share one list of pages already read, so none reads a page twice.
- **Measured.** `dh research score` reads a session log and reports searches, page reads, repeats, tokens and the cost
  per proven fact, and compares two runs.

**Proof you can rerun:** CI on Ubuntu and Windows runs 46 try-on + 76 control-plane + 40 server-client + 17 repo
tests, all offline (quotes are checked against a local web server in the tests). Not yet measured: a before/after
research run on a real business; `dh research score --baseline` is the tool for it.
